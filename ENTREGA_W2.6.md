# Entrega - Workshop 2.6

## Evidencias necessarias

- Workflow `ci.yml` com os jobs `build-and-test` e `deploy`.
- Actions do Pull Request mostrando os testes executados e o deploy como
  `skipped`.
- Actions apos o merge na `main`, com os dois jobs concluidos.
- Configuracao de Pages usando `GitHub Actions`.
- URL do relatorio publicado no GitHub Pages.

## Fluxo

1. Criar uma branch para a atividade.
2. Fazer commit e push do workflow.
3. Abrir o Pull Request.
4. Conferir o CI no Pull Request.
5. Fazer o merge na `main` quando autorizado.
6. Conferir o deploy e abrir a URL do Pages.
